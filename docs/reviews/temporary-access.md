## Б. Ограничения СБ

1. **Конфигурация остаётся в браузере** — истинно. В диффе нет `fetch`, `XMLHttpRequest`, `navigator.sendBeacon`, `WebSocket`; новые поля живут в той же конфигурации и в том же файле.
2. **Импорт проверяется целиком** — истинно. `readTime` и проверка порядка границ в `readPermission` (`src/app/config-file.ts`) только добавляют ошибки в общий список, разбор по-прежнему возвращает `ok: false` до любого изменения; сохранённая копия читается тем же `parseConfigFile`.
3. **Операции затрагивают только выбранные разрешения** — истинно. `addPermission` дописывает одну запись в конец, не трогая остальные; `removePermission` не менялся; учебные данные без интервалов, `p1`–`p5` прежние.
4. **Отзыв сохраняет независимые источники** — истинно. `p1` и `p2` постоянные, `isWithinInterval` для них всегда истинна на любом `at`, поэтому после отзыва `p1` источником остаётся группа «Бухгалтерия».

## В. Архитектурные правила

- **Единый модуль расчёта** — соблюдено. Интервал проверяется одной функцией `isWithinInterval` в `src/domain/access.ts` для прямых и групповых разрешений; компоненты только показывают интервал (`describeInterval`) и не считают доступ.
- **Время передаётся параметром** — соблюдено. `at` стал `LocalDateTime`, в `src/domain` нет `Date.now()` и `new Date()` без аргументов (`time.ts` строит `Date` только из переданных чисел и форматирует переданный `Date`). Текущее время берёт `src/app/index.ts` (`now`), компонент получает его через `defaultEvaluationTime`.
- **Компоненты через слой приложения** — соблюдено для импортов: `App.tsx` и `PermissionsPanel.tsx` импортируют только из `../app`, `localStorage` не читают. Тест `TemporaryAccess.test.tsx` берёт `exportConfig` и `seedConfig` из `src/app`, что разрешено разделом «Тесты».
- **Граница типов** — нарушено размещение нового общего типа `Interval` (находка 1). `LocalDateTime` объявлен в `src/domain/time.ts` и реэкспортирован верно; `GrantResult` с `"invalid-interval"` объявлен в `src/app/index.ts` верно.

## Г. Покрытие (сценарий → тест)

`temporary-access`:
- Смена момента меняет ответ → `TemporaryAccess.test.tsx` «временное разрешение действует только внутри интервала».
- Значение по умолчанию → `TemporaryAccess.test.tsx` «по умолчанию момент расчёта — текущее время браузера…».
- Выдача временного разрешения → `TemporaryAccess.test.tsx` «временное разрешение действует только внутри интервала» (сообщение) и «показывает интервал в строке разрешения».
- Окончание раньше начала → `TemporaryAccess.test.tsx` «не выдаёт разрешение, если окончание не позже начала»; равенство — `permissions.test.ts` «проверяет интервал: формат и окончание позже начала».
- Внутри интервала → `access.test.ts` «даёт доступ внутри интервала и называет источник», `TemporaryAccess.test.tsx` «…только внутри интервала».
- Первая минута интервала → `access.test.ts` «начало входит в интервал».
- До начала → `access.test.ts` «начало входит в интервал», `TemporaryAccess.test.tsx` «…только внутри интервала» (`access-sources` скрыт).
- Момент окончания → `access.test.ts` «окончание в интервал не входит», `TemporaryAccess.test.tsx` «…только внутри интервала».
- Только начало → `access.test.ts` «только начало: действует с начала без окончания».
- Только окончание → `access.test.ts` «только окончание: действует до окончания».
- Участник группы внутри и вне интервала → `TemporaryAccess.test.tsx` «временное разрешение группы действует для участника и называет группу», `access.test.ts` «временное разрешение группы…».
- Два источника, затем один → `TemporaryAccess.test.tsx` «временное рядом с постоянным: внутри два источника, после окончания один», `access.test.ts` «постоянное и временное вместе…».
- Постоянное на любой момент → `TemporaryAccess.test.tsx` и `access.test.ts` «постоянное разрешение действует на любой момент».

`access-calculation`:
- Новая выдача учитывается расчётом сразу → `Permissions.test.tsx` «добавляет разрешение, и расчёт сразу его учитывает» (тест вне диффа, не менялся).
- Повторная выдача → `Permissions.test.tsx` «сообщает о повторной выдаче и не создаёт дубль» (вне диффа, не менялся).
- Временное рядом с постоянным не повтор → `permissions.test.ts` «временное разрешение рядом с постоянным выдаётся», сообщение — `TemporaryAccess.test.tsx` «временное рядом с постоянным…».
- Повтор временного с тем же интервалом → `permissions.test.ts` «повтор с тем же интервалом не создаёт дубль».

`config-import`:
- Экспорт и импорт временного разрешения → `config-file.test.ts` «сохраняет интервал при экспорте и обратном импорте».
- Постоянное разрешение без новых полей → `config-file.test.ts` «не пишет поля интервала у постоянных разрешений».
- Неверный формат времени → `config-file.test.ts` «отвергает время неверного вида».
- Окончание раньше начала в файле → `config-file.test.ts` «отвергает окончание не позже начала».
- Старый файл → `TemporaryAccess.test.tsx` «файл прежнего формата принимается, и доступ считается как раньше».

Сценариев без теста нет.
